# WritePretty

A lightweight browser-based text cleanup tool that improves consistency and readability using simple, rule-based processing.

WritePretty makes small, predictable corrections while preserving the user's original wording. It does not use AI to rewrite text, and all processing is performed locally in the browser.

## Overview

WritePretty helps clean common text issues such as spacing, punctuation, capitalisation, unnecessary line breaks, and selected Markdown formatting.

Users can control which cleanup rules are applied, compare the original and processed text side by side, and use the browser's built-in spellcheck to identify possible spelling mistakes.

## Goals

- Reduce time spent on simple text cleanup
- Keep text processing easy to understand
- Produce predictable results
- Preserve the user's original wording
- Give users control over cleanup rules
- Keep text private through local processing

## Features

- Real-time text cleanup
- Spacing, punctuation, and capitalisation correction
- Individual cleanup controls
- Optional Markdown and extra line-break removal
- Browser-based spellcheck
- Protection for code, URLs, and email addresses
- Side-by-side Original and Pretty views
- History Mode with up to five entries
- Combined history preview
- Synchronised scrolling
- Word and character counts
- Copy and download processed text
- Local workspace autosave and reset
- Responsive layout

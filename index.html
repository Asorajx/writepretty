Automatic cleanup

WritePretty uses simple rules to clean spacing, punctuation, and capitalisation. Individual cleanup rules can be changed using .

Spelling

Spelling is checked by your browser. Misspelled words may appear with a red underline, depending on your browser settings. WritePretty does not automatically replace spelling mistakes.

Markdown

Markdown formatting can be preserved or removed using Controls, including headings, bullets, numbered lists, quotes, and emphasis.

Protected content

Code, URLs, and email addresses are protected where possible so cleanup rules do not accidentally change their contents.

History

History Mode keeps up to five separate text entries. Use the numbered tabs to switch between entries, + to create a new entry, and ⊕ to view all entries together.
